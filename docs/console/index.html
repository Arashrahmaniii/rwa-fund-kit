    Actions

    Public demo controls. On a real fund these are three separate organisations; here one test contract plays them all so you can run a dealing day yourself.

    1. Onboard: you become a verified investor and receive 100,000 test USDC.
    2. Investor tab: request a subscription.
    3. Close the epoch (the cut-off). Requests are now locked.
    4. Value and settle, in a later block. The NAV moves by the drift you choose.
    5. Investor tab: claim your shares.
